# Team 1 assets — Homepage · WebGL 3D

Drop any **local** files this page needs here (3D models `.glb`/`.gltf`, textures, HDR env maps).
Reference them from `index.html` with a relative path, e.g. `assets/team1/scene.glb`.

You don't have to use this folder: you can also load assets straight from a URL/CDN
(jsDelivr, the three.js examples CDN, etc.) or generate them procedurally in code.
If you don't need local files, ignore this folder.

Upload files here with **Add file → Upload files** on GitHub — no terminal needed.
